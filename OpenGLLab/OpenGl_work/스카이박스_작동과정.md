## 개요

스카이박스(Skybox)는 3D 게임이나 시뮬레이션에서 배경 하늘을 표현하는 기법입니다. 카메라를 중심으로 하는 거대한 큐브에 텍스처를 입혀서, 플레이어가 어느 방향을 보든 하늘이 보이도록 구현합니다.

### 스카이박스의 특징
- **항상 배경으로 렌더링**: 모든 오브젝트보다 뒤에 그려짐
- **카메라와 함께 회전**: 카메라가 회전하면 스카이박스도 함께 회전
- **카메라 이동 무시**: 카메라가 이동해도 스카이박스는 항상 같은 위치에 있음
- **큐브맵 텍스처 사용**: 6개의 면 이미지를 하나의 큐브맵으로 구성

{

		-1.0f, -1.0f, -1.0f, -1.0f, -1.0f,  1.0f,  1.0f, -1.0f, -1.0f,
		 1.0f, -1.0f, -1.0f, -1.0f, -1.0f,  1.0f,  1.0f, -1.0f,  1.0f
	};

	// VAO, VBO 생성
	glGenVertexArrays(1, &skyboxVAO);
	glGenBuffers(1, &skyboxVBO);
	
	// VAO 바인딩 (이후 설정은 이 VAO에 저장됨)
	glBindVertexArray(skyboxVAO);
	
	// VBO에 정점 데이터 업로드
	glBindBuffer(GL_ARRAY_BUFFER, skyboxVBO);
	glBufferData(GL_ARRAY_BUFFER, sizeof(skyboxVertices), &skyboxVertices, GL_STATIC_DRAW);
	
	// 정점 속성 설정 (위치만 사용, layout = 0)
	glEnableVertexAttribArray(0);
	glVertexAttribPointer(0, 3, GL_FLOAT, GL_FALSE, 3 * sizeof(float), (void*)0);
	
	// 바인딩 해제
	glBindVertexArray(0);

#### 상세 설명

**2.1 큐브 정점 데이터 구조**
- **6개 면**: 앞, 뒤, 위, 아래, 왼쪽, 오른쪽
- **각 면 2개 삼각형**: OpenGL은 삼각형만 렌더링하므로 사각형 면을 2개 삼각형으로 분할
- **총 36개 정점**: 6면 × 2삼각형 × 3정점 = 36개
- **정점 좌표 범위**: -1.0 ~ 1.0 (정규화된 좌표계)

**2.2 VAO/VBO 생성 과정**
1. `glGenVertexArrays(1, &skyboxVAO)`: VAO(Vertex Array Object) 생성
   - VAO는 정점 속성 설정을 저장하는 객체입니다.
2. `glGenBuffers(1, &skyboxVBO)`: VBO(Vertex Buffer Object) 생성
   - VBO는 정점 데이터를 GPU 메모리에 저장하는 버퍼입니다.
3. `glBindVertexArray(skyboxVAO)`: VAO 바인딩
   - 이후의 모든 설정이 이 VAO에 저장됩니다.
4. `glBindBuffer(GL_ARRAY_BUFFER, skyboxVBO)`: VBO 바인딩
5. `glBufferData(...)`: 정점 데이터를 GPU 메모리에 업로드
   - `GL_STATIC_DRAW`: 데이터가 변경되지 않음을 의미
6. `glEnableVertexAttribArray(0)`: 정점 속성 0번 활성화
7. `glVertexAttribPointer(0, 3, GL_FLOAT, ...)`: 정점 속성 설정
   - 위치: 0번 속성
   - 크기: 3개 (x, y, z)
   - 타입: GL_FLOAT
   - 스트라이드: 3 * sizeof(float) (다음 정점까지의 바이트 수)
   - 오프셋: 0 (시작 위치)

### 3. 큐브맵 텍스처 로드 (`loadCubemap`)

```419:474:OpenGl_work/src/main.cpp
unsigned int loadCubemap(const std::vector<std::string>& faces)
{
	// HDR 파일인지 확인하는 람다 함수
	auto isHDR = [](const std::string& path) {
		auto lower = path;
		std::transform(lower.begin(), lower.end(), lower.begin(), [](unsigned char c) { return static_cast<char>(std::tolower(c)); });
		return lower.rfind(".hdr") != std::string::npos || lower.rfind(".exr") != std::string::npos;
	};

	// 큐브맵 텍스처 생성
	unsigned int textureID;
	glGenTextures(1, &textureID);
	glBindTexture(GL_TEXTURE_CUBE_MAP, textureID);

	int width = 0, height = 0, nrChannels = 0;
	// 스카이박스는 Y축을 뒤집지 않음
	stbi_set_flip_vertically_on_load(false);

	// 6면의 이미지를 각각 로드
	for (unsigned int i = 0; i < faces.size(); i++)
	{
		if (isHDR(faces[i])) {
			// HDR 이미지 로드 (32비트 부동소수점)
			float* data = stbi_loadf(faces[i].c_str(), &width, &height, &nrChannels, 0);
			if (data) {
				GLenum format = (nrChannels == 4) ? GL_RGBA : GL_RGB;
				GLenum internalFormat = (nrChannels == 4) ? GL_RGBA16F : GL_RGB16F;  // HDR용 16비트 부동소수점
				// 큐브맵의 각 면에 이미지 데이터 설정
				glTexImage2D(GL_TEXTURE_CUBE_MAP_POSITIVE_X + i, 0, internalFormat, width, height, 0, format, GL_FLOAT, data);
				stbi_image_free(data);
			} else {
				std::cout << "Failed to load HDR cubemap: " << faces[i] << std::endl;
			}
		} else {
			// 일반 이미지 로드 (8비트 정수)
			unsigned char* data = stbi_load(faces[i].c_str(), &width, &height, &nrChannels, 0);
			if (data) {
				GLenum format = (nrChannels == 4) ? GL_RGBA : GL_RGB;
				// 큐브맵의 각 면에 이미지 데이터 설정
				glTexImage2D(GL_TEXTURE_CUBE_MAP_POSITIVE_X + i, 0, format, width, height, 0, format, GL_UNSIGNED_BYTE, data);
				stbi_image_free(data);
			} else {
				std::cout << "Failed to load cubemap: " << faces[i] << std::endl;
			}
		}
	}

	// 텍스처 파라미터 설정
	glTexParameteri(GL_TEXTURE_CUBE_MAP, GL_TEXTURE_MIN_FILTER, GL_LINEAR);  // 축소 필터
	glTexParameteri(GL_TEXTURE_CUBE_MAP, GL_TEXTURE_MAG_FILTER, GL_LINEAR);  // 확대 필터
	glTexParameteri(GL_TEXTURE_CUBE_MAP, GL_TEXTURE_WRAP_S, GL_CLAMP_TO_EDGE);  // 경계 처리
	glTexParameteri(GL_TEXTURE_CUBE_MAP, GL_TEXTURE_WRAP_T, GL_CLAMP_TO_EDGE);
	glTexParameteri(GL_TEXTURE_CUBE_MAP, GL_TEXTURE_WRAP_R, GL_CLAMP_TO_EDGE);

	return textureID;
}
```

#### 상세 설명

**3.1 큐브맵 텍스처 생성**
- `glGenTextures(1, &textureID)`: 텍스처 객체 생성
- `glBindTexture(GL_TEXTURE_CUBE_MAP, textureID)`: 큐브맵 텍스처 타입으로 바인딩
  - `GL_TEXTURE_CUBE_MAP`는 6개의 2D 텍스처를 하나로 묶은 특수한 텍스처 타입입니다.

**3.2 이미지 로드**
- `stbi_set_flip_vertically_on_load(false)`: Y축 뒤집기 비활성화
  - 스카이박스는 일반적으로 Y축을 뒤집지 않습니다.
- **HDR 이미지 지원**:
  - `.hdr` 또는 `.exr` 확장자 감지
  - `stbi_loadf()`: 32비트 부동소수점으로 로드
  - `GL_RGB16F` 또는 `GL_RGBA16F`: 16비트 부동소수점 내부 포맷 사용
  - HDR은 더 넓은 밝기 범위를 표현할 수 있어 실사적인 조명 효과를 제공합니다.
- **일반 이미지**:
  - `stbi_load()`: 8비트 정수로 로드
  - `GL_RGB` 또는 `GL_RGBA`: 일반 포맷 사용

**3.3 큐브맵 면 할당**
- `GL_TEXTURE_CUBE_MAP_POSITIVE_X + i`: 각 면을 큐브맵에 할당
  - `i = 0`: `GL_TEXTURE_CUBE_MAP_POSITIVE_X` (오른쪽)
  - `i = 1`: `GL_TEXTURE_CUBE_MAP_NEGATIVE_X` (왼쪽)
  - `i = 2`: `GL_TEXTURE_CUBE_MAP_POSITIVE_Y` (위)
  - `i = 3`: `GL_TEXTURE_CUBE_MAP_NEGATIVE_Y` (아래)
  - `i = 4`: `GL_TEXTURE_CUBE_MAP_POSITIVE_Z` (앞)
  - `i = 5`: `GL_TEXTURE_CUBE_MAP_NEGATIVE_Z` (뒤)

**3.4 텍스처 파라미터 설정**
- `GL_TEXTURE_MIN_FILTER = GL_LINEAR`: 축소 시 선형 필터링 (부드러운 축소)
- `GL_TEXTURE_MAG_FILTER = GL_LINEAR`: 확대 시 선형 필터링 (부드러운 확대)
- `GL_TEXTURE_WRAP_S/T/R = GL_CLAMP_TO_EDGE`: 경계에서 가장자리 색상으로 클램핑
  - 스카이박스는 경계가 보이지 않도록 가장자리 색상을 반복합니다.

### 4. 스카이박스 초기화 (`initSkybox`)

```478:497:OpenGl_work/src/main.cpp
unsigned int initSkybox(Shader& skyboxShader, unsigned int& skyboxVAO, unsigned int& skyboxVBO)
{
	// 스카이박스 정점 데이터 설정
	setupSkyboxData(skyboxVAO, skyboxVBO);

	// 6면의 이미지 파일 경로 (순서: 오른쪽, 왼쪽, 위, 아래, 앞, 뒤)
	std::vector<std::string> skyboxFaces = {
		"assets/skybox/right.hdr", "assets/skybox/left.hdr",
		"assets/skybox/top.hdr",   "assets/skybox/bottom.hdr",
		"assets/skybox/front.hdr", "assets/skybox/back.hdr"
	};

	// 큐브맵 텍스처 로드
	unsigned int cubemapTexture = loadCubemap(skyboxFaces);
	
	// 셰이더에 텍스처 유닛 번호 설정
	skyboxShader.use();
	skyboxShader.setInt("skybox", 0);  // GL_TEXTURE0 사용
	return cubemapTexture;
}
```

**4.1 초기화 순서**
1. `setupSkyboxData()`: 정점 데이터 설정 (VAO, VBO 생성)
2. 이미지 파일 경로 정의: 6개 면의 이미지 경로를 순서대로 지정
3. `loadCubemap()`: 큐브맵 텍스처 로드
4. 셰이더에 텍스처 유닛 설정: `skybox` 유니폼 변수에 텍스처 유닛 0번 할당

**4.2 이미지 파일 순서**
- **순서 중요**: 큐브맵의 각 면은 특정 순서로 할당되어야 합니다.

  - 2번: 위 (top)
  - 3번: 아래 (bottom)
  - 4번: 앞 (front)
  - 5번: 뒤 (back)

#### 단계별 상세 설명

**1단계: 깊이 테스트 변경**
```cpp
glDepthFunc(GL_LEQUAL);
```
- **목적**: 스카이박스가 항상 배경으로 렌더링되도록 설정
- **GL_LEQUAL**: 깊이 값이 같거나 작으면 통과 (기본값은 `GL_LESS`)
- 스카이박스의 깊이 값은 최대값(1.0)으로 설정되므로, 다른 오브젝트보다 뒤에 그려집니다.

**2단계: 셰이더 활성화**
```cpp
skyboxShader.use();
```
- 스카이더 프로그램을 활성화하여 이후 설정이 이 셰이더에 적용되도록 합니다.

**3단계: 뷰 행렬 설정 (핵심)**
```cpp
glm::mat4 view = glm::mat4(glm::mat3(camera.GetViewMatrix()));
```
- **`camera.GetViewMatrix()`**: 카메라의 전체 뷰 행렬 (회전 + 이동 포함)
- **`glm::mat3(...)`**: 3×3 행렬로 변환 (회전 정보만 추출)
  - 4×4 행렬에서 상단 3×3 부분만 가져옵니다.
  - 이 부분에는 회전 정보가 포함되어 있습니다.
- **`glm::mat4(...)`**: 다시 4×4 행렬로 변환
  - 이동 정보는 제거되고, 회전 정보만 남습니다.
- **결과**: 카메라가 회전하면 스카이박스도 회전하지만, 이동은 무시됩니다.

**4단계: 투영 행렬 설정**
```cpp
glm::mat4 projection = glm::perspective(glm::radians(camera.Zoom), (float)SCR_WIDTH / (float)SCR_HEIGHT, 0.1f, 100.0f);
```
- 원근 투영 행렬 생성
- `camera.Zoom`: 시야각 (FOV)
- `SCR_WIDTH / SCR_HEIGHT`: 종횡비
- `0.1f, 100.0f`: 근거리/원거리 클리핑 평면

**5단계: 셰이더에 행렬 전달**
```cpp
skyboxShader.setMat4("view", view);
skyboxShader.setMat4("projection", projection);
```
- 버텍스 셰이더의 유니폼 변수에 행렬을 전달합니다.

**6단계: VAO 바인딩**
```cpp
glBindVertexArray(skyboxVAO);
```
- 스카이박스의 정점 데이터를 사용하기 위해 VAO를 바인딩합니다.

**7단계: 텍스처 바인딩**
```cpp
glActiveTexture(GL_TEXTURE0);
glBindTexture(GL_TEXTURE_CUBE_MAP, cubemapTexture);
```
- `glActiveTexture(GL_TEXTURE0)`: 텍스처 유닛 0번 활성화
- `glBindTexture(...)`: 큐브맵 텍스처를 활성화된 텍스처 유닛에 바인딩

**8단계: 그리기**
```cpp
glDrawArrays(GL_TRIANGLES, 0, 36);
```
- `GL_TRIANGLES`: 삼각형 모드로 렌더링
- `0`: 시작 인덱스
- `36`: 정점 개수 (6면 × 2삼각형 × 3정점)

**9단계: 정리**
```cpp
glBindVertexArray(0);
glDepthFunc(GL_LESS);
```
- VAO 바인딩 해제
- 깊이 테스트를 원래대로 복원 (다른 오브젝트 렌더링을 위해)

```1:15:OpenGl_work/shaders/skybox.vs
#version 330 core
layout (location = 0) in vec3 aPos;

out vec3 TexCoords;

uniform mat4 view;
uniform mat4 projection;

void main()
{
    TexCoords = aPos;
    vec4 pos = projection * view * vec4(aPos, 1.0);
    gl_Position = pos.xyww; // 원근 분모 w 유지
}
```

#### 상세 설명

**입력:**
- `layout (location = 0) in vec3 aPos`: 정점 위치 (VAO의 0번 속성에서 가져옴)

**출력:**
- `out vec3 TexCoords`: 프래그먼트 셰이더로 전달할 텍스처 좌표

**유니폼 변수:**
- `uniform mat4 view`: 뷰 행렬 (카메라 회전만 포함)
- `uniform mat4 projection`: 투영 행렬

**동작 과정:**
1. **텍스처 좌표 설정**: `TexCoords = aPos`
   - 정점의 위치 좌표를 그대로 텍스처 좌표로 사용
   - 큐브맵은 3D 방향 벡터를 사용하여 샘플링합니다.
   - 예: 정점이 (1, 0, 0)이면 오른쪽 면의 텍스처를 샘플링합니다.

2. **공간 변환**: `vec4 pos = projection * view * vec4(aPos, 1.0)`
   - 정점을 클립 공간으로 변환
   - `view`: 월드 공간 → 뷰 공간 (카메라 좌표계)
   - `projection`: 뷰 공간 → 클립 공간 (화면 좌표계)

3. **깊이 값 설정**: `gl_Position = pos.xyww`
   - **핵심**: z 성분을 w 성분으로 대체
   - `pos.xyww`는 `(pos.x, pos.y, pos.w, pos.w)`를 의미
   - 깊이 값(z)을 w로 설정하면, 깊이 버퍼에 최대값(1.0)이 저장됩니다.
   - 이렇게 하면 스카이박스가 항상 배경으로 렌더링됩니다.

### 프래그먼트 셰이더 (`skybox.fs`)

```1:12:OpenGl_work/shaders/skybox.fs
#version 330 core
out vec4 FragColor;

in vec3 TexCoords;

uniform samplerCube skybox;

void main()
{
    FragColor = texture(skybox, TexCoords);
}
```

#### 상세 설명

**입력:**
- `in vec3 TexCoords`: 버텍스 셰이더에서 전달된 텍스처 좌표 (3D 방향 벡터)

**유니폼 변수:**
- `uniform samplerCube skybox`: 큐브맵 텍스처 샘플러

**동작:**
- `texture(skybox, TexCoords)`: 큐브맵에서 샘플링
  - `TexCoords`는 3D 방향 벡터입니다.
  - 큐브맵은 이 방향 벡터를 사용하여 해당 방향의 텍스처를 샘플링합니다.
  - 예: `(1, 0, 0)`이면 오른쪽 면, `(0, 1, 0)`이면 위쪽 면을 샘플링합니다.

**결과:**
- `FragColor`: 최종 픽셀 색상 (화면에 출력될 색상)

## 핵심 기술 포인트

### 1. 뷰 행렬에서 이동 제거

```cpp
glm::mat4 view = glm::mat4(glm::mat3(camera.GetViewMatrix()));
```

**왜 필요한가?**
- 스카이박스는 무한히 먼 배경을 표현합니다.
- 카메라가 이동해도 스카이박스는 항상 같은 위치에 있어야 합니다.
- 하지만 카메라가 회전하면 스카이박스도 함께 회전해야 합니다.

**작동 원리:**
- 4×4 변환 행렬의 구조:
  ```
  [ 회전  | 이동 ]
  [-------|-----]
  [ 0 0 0 |  1  ]
  ```
- 상단 3×3 부분: 회전 정보
- 우측 상단 3×1 부분: 이동 정보
- `glm::mat3()`으로 변환하면 회전 정보만 남습니다.

### 2. 깊이 테스트 변경

```cpp
glDepthFunc(GL_LEQUAL);  // 렌더링 전
// ... 스카이박스 렌더링 ...
glDepthFunc(GL_LESS);    // 렌더링 후
```

**왜 필요한가?**
- 스카이박스의 깊이 값은 최대값(1.0)으로 설정됩니다.
- 기본 깊이 테스트(`GL_LESS`)는 깊이 값이 작을 때만 통과합니다.
- 스카이박스의 깊이 값(1.0)은 다른 오브젝트의 깊이 값보다 크므로 기본 설정으로는 렌더링되지 않습니다.
- `GL_LEQUAL`로 변경하면 깊이 값이 같거나 작을 때 통과하므로, 스카이박스가 배경으로 렌더링됩니다.

### 3. 원근 분모 w 유지

```glsl
gl_Position = pos.xyww;
```

**왜 필요한가?**
- `pos.xyww`는 `(pos.x, pos.y, pos.w, pos.w)`를 의미합니다.
- z 성분을 w로 설정하면, 깊이 버퍼에 최대값이 저장됩니다.
- 이렇게 하면 스카이박스가 항상 배경으로 렌더링됩니다.

**수학적 설명:**
- 깊이 버퍼의 값은 `z / w`로 계산됩니다.
- `z = w`이므로 `z / w = 1.0` (최대 깊이 값)
- 모든 오브젝트의 깊이 값은 0.0 ~ 1.0 범위이므로, 스카이박스는 항상 가장 뒤에 그려집니다.

### 4. HDR 이미지 지원

```cpp
if (isHDR(faces[i])) {
    float* data = stbi_loadf(faces[i].c_str(), &width, &height, &nrChannels, 0);
    GLenum internalFormat = (nrChannels == 4) ? GL_RGBA16F : GL_RGB16F;
    glTexImage2D(..., internalFormat, ..., GL_FLOAT, data);
}
```

**HDR의 장점:**
- **넓은 밝기 범위**: 일반 이미지(8비트)는 0~255 범위만 표현하지만, HDR은 더 넓은 범위를 표현합니다.
- **실사적인 조명**: 실제 하늘의 밝기 변화를 더 정확하게 표현할 수 있습니다.
- **후처리 효과**: 블룸(Bloom), 톤 매핑(Tone Mapping) 등의 효과를 적용할 수 있습니다.

## 요약

스카이박스 구현의 핵심은 다음과 같습니다:

1. **큐브 기하학**: 6개 면, 각 면 2개 삼각형, 총 36개 정점
2. **큐브맵 텍스처**: 6개의 이미지를 하나의 큐브맵으로 구성
3. **뷰 행렬 조작**: 카메라 회전만 사용, 이동은 무시
4. **깊이 테스트**: `GL_LEQUAL`로 변경하여 배경으로 렌더링
5. **깊이 값 조작**: `gl_Position = pos.xyww`로 최대 깊이 값 설정
6. **HDR 지원**: 넓은 밝기 범위 표현

이러한 기법들을 통해 스카이박스는 항상 배경으로 렌더링되며, 카메라 회전에 따라 자연스럽게 회전하는 하늘을 표현할 수 있습니다.
