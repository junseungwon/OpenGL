# 🎬 애니메이션 동작 흐름 - main부터 렌더링까지

main 함수에서 시작해서 애니메이션이 어떻게 동작하는지 전체 흐름을 단계별로 설명합니다.

---

## 📋 전체 흐름 개요

```
main() 시작
  ↓
1. 초기화 (한 번만 실행)
   ├─ OpenGL 초기화
   ├─ 셰이더 로드
   └─ 게임 오브젝트 초기화
       ├─ Player.Init() → 모델/애니메이션 로드
       └─ Enemy.Init() → 모델/애니메이션 로드
  ↓
2. 게임 루프 (매 프레임 반복)
   ├─ 시간 업데이트 (deltaTime 계산)
   ├─ 게임 로직 업데이트
   │   ├─ player.UpdateActions(deltaTime)
   │   │   └─ CharacterBase::Update(deltaTime)
   │   │       └─ Animator::UpdateAnimation(deltaTime)
   │   │           └─ 뼈대 변환 행렬 계산
   │   └─ enemy.UpdateActions(deltaTime)
   │       └─ (같은 과정)
   ├─ 그림자 맵 렌더링
   ├─ 메인 씬 렌더링
   │   └─ CharacterBase::Render()
   │       └─ 뼈대 행렬을 셰이더에 전달
   │           └─ GPU에서 정점 변환
   └─ 화면 출력
```

---

## 🔍 단계별 상세 설명

### 📌 1단계: 초기화 (main 함수 시작 부분)

#### 1-1. OpenGL 및 셰이더 초기화

```cpp
// main.cpp
int main()
{
    // GLFW, GLAD 초기화
    GLFWwindow* window = initGLFWAndCreateWindow(...);
    initGLAD();
    
    // 셰이더 로드
    Shader skinnedShader("shaders/animated_model.vs", "shaders/animated_model.fs");
    // ↑ 스켈레탈 애니메이션을 지원하는 셰이더
}
```

**이 시점에서:**
- OpenGL 컨텍스트 준비 완료
- 셰이더 파일 로드 완료 (아직 사용 안 함)

---

#### 1-2. 플레이어 초기화 (핵심!)

```cpp
// main.cpp
Player player;
if (!player.Init()) { ... }
```

**Player::Init() 내부 동작:**

```cpp
// Player.h - Init() 함수
bool Init()
{
    // 1. 모델 로드
    if (!LoadModel("assets/models/Player/IdlePlayer.fbx")) return false;
    //    ↓
    // CharacterBase::LoadModel() 호출
    //    ↓
    // Model model("IdlePlayer.fbx") 생성
    //    ↓
    // Assimp으로 FBX 파일 읽기
    //    ↓
    // - 정점 데이터 추출
    // - 뼈대 정보 추출 (뼈대 ID, 오프셋 행렬)
    // - 각 정점에 뼈대 ID와 가중치 저장
    //    ↓
    // model_ 멤버 변수에 저장 완료
    
    // 2. 애니메이션 등록
    if (!AddAnimation("idle", "assets/models/Player/IdlePlayer.fbx")) return false;
    //    ↓
    // CharacterBase::AddAnimation() 호출
    //    ↓
    // Animation anim("IdlePlayer.fbx", model_) 생성
    //    ↓
    // Animation 생성자 내부:
    //    - Assimp으로 FBX 파일 읽기
    //    - 애니메이션 정보 추출 (Duration, TicksPerSecond)
    //    - 각 뼈대의 키프레임 데이터 읽기
    //    - 뼈대 계층 구조 읽기
    //    ↓
    // animations_["idle"] = anim 저장
    // durations_["idle"] = 3.0초 (예시) 저장
    //    ↓
    // 첫 번째 애니메이션이므로 Animator 생성
    // animator_ = new Animator(animations_["idle"])
    //    ↓
    // Animator 생성자:
    //    - m_CurrentAnimation = animations_["idle"]
    //    - m_CurrentTime = 0.0f
    //    - m_FinalBoneMatrices[100] 배열 초기화 (단위 행렬)
    
    // 3. 나머지 애니메이션 등록
    AddAnimation("attack", "AttackPlayer.fbx");
    AddAnimation("slash", "SlashPlayer.fbx");
    AddAnimation("cast", "CastingPlayer.fbx");
    // 각각 Animation 객체 생성되어 animations_ 맵에 저장
    
    // 4. 기본 애니메이션 재생
    PlayAnimation("idle");
    //    ↓
    // CharacterBase::PlayAnimation() 호출
    //    ↓
    // animator_->PlayAnimation(animations_["idle"])
    //    ↓
    // Animator::PlayAnimation() 내부:
    //    - m_CurrentAnimation = animations_["idle"]
    //    - m_CurrentTime = 0.0f (리셋)
    
    return true;
}
```

**초기화 완료 시점의 상태:**

```
Player 객체:
├─ model_ → Model 객체 (정점, 뼈대 정보 포함)
├─ animator_ → Animator 객체
│   ├─ m_CurrentAnimation → "idle" 애니메이션
│   ├─ m_CurrentTime = 0.0f
│   └─ m_FinalBoneMatrices[100] → 모두 단위 행렬
└─ animations_ 맵
    ├─ "idle" → Animation 객체
    ├─ "attack" → Animation 객체
    ├─ "slash" → Animation 객체
    └─ "cast" → Animation 객체
```

### 📌 2단계: 게임 루프 (매 프레임 반복)

#### 2-1. 시간 업데이트

```cpp
// main.cpp - 게임 루프
while (!glfwWindowShouldClose(window))
{
    // 델타 타임 계산
    float currentFrame = static_cast<float>(glfwGetTime());
    deltaTime = currentFrame - lastFrame;  // 예: 0.016초 (60fps)
    lastFrame = currentFrame;
```

**deltaTime의 의미:**
- 이전 프레임과 현재 프레임 사이의 시간 차이
- 예: 60fps → deltaTime ≈ 0.016초
- 애니메이션 시간을 진행시키는 데 사용

---

#### 2-2. 게임 로직 업데이트 (애니메이션 업데이트)

```cpp
// main.cpp
enemy.UpdateActions(deltaTime);
player.UpdateActions(deltaTime);
```

**Player::UpdateActions(deltaTime) 내부 동작:**

```cpp
// Player.h - UpdateActions() 함수
void UpdateActions(float dt)
{
    // 1. 기본 애니메이션 업데이트
    Update(dt);
    //    ↓
    // CharacterBase::Update(dt) 호출
    //    ↓
    // animator_->UpdateAnimation(dt)
    //    ↓
    // Animator::UpdateAnimation(dt) 내부:
    //    - m_CurrentTime += TicksPerSecond * dt
    //      예: 30틱/초 * 0.016초 = 0.48틱 증가
    //    - m_CurrentTime = fmod(m_CurrentTime, Duration)  // 루프
    //    - CalculateBoneTransform(루트 노드, 단위 행렬)
    //      ↓
    //      CalculateBoneTransform() 재귀 호출:
    //        1. 현재 노드의 뼈대 찾기
    //        2. Bone::Update(m_CurrentTime) 호출
    //           - 키프레임 보간 (위치, 회전, 크기)
    //           - m_LocalTransform 계산
    //        3. 글로벌 변환 = 부모 변환 × 로컬 변환
    //        4. 최종 변환 = 글로벌 변환 × 오프셋
    //        5. m_FinalBoneMatrices[뼈대ID] = 최종 변환 저장
    //        6. 자식 노드들도 재귀적으로 처리
    
    // 2. 액션 타이머 업데이트
    if (attack_.playing) {
        attack_.timer += dt;
        if (attack_.timer >= attack_.duration) {
            // 액션 끝 → idle로 복귀
            PlayAnimation("idle");
            attack_.playing = false;
            onActionFinished_();  // 콜백 호출
        }
    }
    // (slash_, cast_도 동일)
}
```

**애니메이션 업데이트 후 상태:**

```
Animator:
├─ m_CurrentTime = 0.48틱 (예시)
└─ m_FinalBoneMatrices[100]
    ├─ [0] = UpperArm의 변환 행렬 (30도 회전)
    ├─ [1] = LowerArm의 변환 행렬 (45도 회전)
    ├─ [2] = Spine의 변환 행렬
    └─ ... (나머지 뼈대들)
```

#### 2-3. 렌더링 (그림자 맵 생성)

```cpp
// main.cpp
// Pass 1: Shadow Map
```

**CharacterBase::RenderDepth() 내부:**

```cpp
// CharacterBase.h - RenderDepth() 함수
void RenderDepth(Shader& shader, const glm::vec3& position, float scale)
{
    // 1. 모델 변환 행렬 생성
    glm::mat4 modelMat = glm::translate(..., position) * glm::scale(..., scale);
    shader.setMat4("model", modelMat);
    
    // 2. 뼈대 변환 행렬을 셰이더에 전달
    auto transforms = animator_->GetFinalBoneMatrices();
    //    ↓
    // Animator::GetFinalBoneMatrices()
    //    return m_FinalBoneMatrices;  // 계산된 뼈대 행렬 배열 반환
    
    for (size_t i = 0; i < boneCount; ++i)
        shader.setMat4("finalBonesMatrices[" + i + "]", transforms[i]);
    //    ↓
    // 셰이더의 uniform 변수에 뼈대 행렬 100개 전달
    
    // 3. 모델 그리기
    model_->Draw(shader);
    //    ↓
    // 각 Mesh::Draw() 호출
    //    ↓
    // GPU에서 정점 변환 수행
}
```

#### 2-4. 메인 씬 렌더링

```cpp
// main.cpp
drawScene(skinnedShader, gDepthMap, lightSpaceMatrix);
```

**drawScene() 내부:**

```cpp
// main.cpp - drawScene() 함수
void drawScene(Shader& skinnedShader, ...)
{
    // 셰이더 공통 설정
    skinnedShader.use();
    skinnedShader.setMat4("projection", projection);
    skinnedShader.setMat4("view", view);
    // ... (조명 설정)
    
    // 플레이어 렌더링
    gPlayerPtr->Render(skinnedShader, ...);
    //    ↓
    // CharacterBase::Render() 호출
    //    ↓
    // (RenderDepth()와 거의 동일하지만 조명이 적용됨)
    // 1. 모델 변환 행렬 설정
    // 2. 뼈대 변환 행렬을 셰이더에 전달
    // 3. model_->Draw(shader) 호출
}
```

**Model::Draw() → Mesh::Draw() → GPU:**

```cpp
// mesh.h - Mesh::Draw() 함수
void Draw(Shader &shader) 
{
    // 텍스처 바인딩
    // ...
    
    // 메시 그리기
    glBindVertexArray(VAO);
    glDrawElements(GL_TRIANGLES, indices.size(), ...);
    //    ↓
    // GPU에서 Vertex Shader 실행
}
```

**GPU에서 일어나는 일 (Vertex Shader):**

```glsl
// animated_model.vs
void main()
{
    // 1. 뼈대 변환 행렬 계산
    mat4 boneTransform = getBoneTransform();
    //    - 정점의 뼈대 ID와 가중치로 변환 행렬 계산
    //    - 예: UpperArm 60% + LowerArm 40%
    
    // 2. 정점 위치 변환
    vec4 localPos = boneTransform * vec4(aPos, 1.0);
    //    - 원래 위치 → 뼈대 변환 적용
    
    // 3. 월드 공간 변환
    vec4 worldPos = model * localPos;
    
    // 4. 화면 좌표 계산
    gl_Position = projection * view * worldPos;
}
```

**결과:**
- 각 정점이 뼈대 변환에 따라 움직임
- 팔을 올리면 팔 주변 정점들이 위로 올라감
- 화면에 애니메이션된 캐릭터가 그려짐!

## 🎯 핵심 포인트

### 1. 초기화 시점
- **모델 로드**: 정점 데이터 + 뼈대 정보 추출
- **애니메이션 로드**: 키프레임 데이터 추출
- **Animator 생성**: 뼈대 변환 행렬 배열 준비

### 2. 매 프레임 업데이트
- **시간 진행**: `m_CurrentTime += TicksPerSecond * deltaTime`
- **뼈대 변환 계산**: 키프레임 보간 → 로컬 변환 → 글로벌 변환
- **최종 행렬 저장**: `m_FinalBoneMatrices[뼈대ID] = 최종 변환`

### 3. 렌더링 시점
- **셰이더에 전달**: 뼈대 행렬 100개를 uniform으로 전달
- **GPU에서 변환**: 각 정점마다 뼈대 가중치로 변환 행렬 계산
- **정점 변환**: `boneTransform × 원래 위치 = 변환된 위치`
