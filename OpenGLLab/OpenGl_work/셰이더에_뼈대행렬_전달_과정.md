# 🎯 렌더링 과정에서 셰이더에 뼈대 행렬 전달하기

Update에서 계산한 뼈대 변환 행렬을 셰이더에 전달하는 전체 과정을 설명합니다.

---

## 📋 전체 흐름

```
Update() → 뼈대 행렬 계산 완료
    ↓
Render() 호출
    ↓
1. Animator에서 뼈대 행렬 배열 가져오기
    ↓
2. 셰이더에 행렬 전달 (for 루프)
    ↓
3. GPU에서 정점 변환
```

---

## 🔍 단계별 상세 설명

### 📌 1단계: Render() 함수 호출

```cpp
// main.cpp - drawScene() 함수
gPlayerPtr->Render(skinnedShader, glm::vec3(2.0f, -1.0f, 0.0f), 0.002f, -90.0f);
```

**이 시점에서:**
- `Update()`가 이미 호출되어 `m_FinalBoneMatrices[100]` 배열이 계산되어 있음
- 각 뼈대의 최종 변환 행렬이 준비되어 있음

---

### 📌 2단계: CharacterBase::Render() 내부

```cpp
// CharacterBase.h - Render() 함수
void Render(Shader& shader, const glm::vec3& position, float scale, float rotationY = 0.0f)
{
    if (!animator_ || !model_) return;

    // 1. 모델 변환 행렬 생성 (위치, 회전, 크기)
    glm::mat4 modelMat = glm::mat4(1.0f);
    modelMat = glm::translate(modelMat, position);
    if (rotationY != 0.0f)
        modelMat = glm::rotate(modelMat, glm::radians(rotationY), glm::vec3(0, 1, 0));
    modelMat = glm::scale(modelMat, glm::vec3(scale));
    shader.setMat4("model", modelMat);
    // ↑ 일반적인 변환 행렬 (위치, 회전, 크기)

    // 2. ⭐ 핵심: 뼈대 변환 행렬을 셰이더에 전달
    auto transforms = animator_->GetFinalBoneMatrices();
    //    ↓
    // Animator::GetFinalBoneMatrices()
    //    return m_FinalBoneMatrices;  // 계산된 뼈대 행렬 배열 반환
    //    예: [0] = UpperArm 변환, [1] = LowerArm 변환, ...
    
    size_t boneCount = std::min(transforms.size(), static_cast<size_t>(MAX_BONES_SHADER));
    // MAX_BONES_SHADER = 100 (셰이더에서 처리할 수 있는 최대 뼈대 개수)
    
    // 3. 각 뼈대 행렬을 셰이더의 uniform 배열에 전달
    for (size_t i = 0; i < boneCount; ++i)
        shader.setMat4("finalBonesMatrices[" + std::to_string(i) + "]", transforms[i]);
    //    ↓
    // Shader::setMat4() 호출
    //    ↓
    // OpenGL의 glUniformMatrix4fv() 호출
    //    ↓
    // GPU의 uniform 변수에 행렬 데이터 전달

    // 4. 모델 그리기
    model_->Draw(shader);
}
```

### 📌 3단계: Shader::setMat4() 함수

```cpp
// shader_m.h - setMat4() 함수
void setMat4(const std::string& name, const glm::mat4& mat) const
{
    glUniformMatrix4fv(glGetUniformLocation(ID, name.c_str()), 1, GL_FALSE, &mat[0][0]);
    //    ↑                    ↑                    ↑         ↑        ↑
    //    |                    |                    |         |        |
    //    |                    |                    |         |        └─ 행렬 데이터 포인터
    //    |                    |                    |         └─ 행렬 전치 여부 (GL_FALSE = 전치 안 함)
    //    |                    |                    └─ 행렬 개수 (1개)
    //    |                    └─ uniform 변수 이름으로 위치 찾기
    //    └─ OpenGL 함수: GPU의 uniform 변수에 행렬 데이터 전달
}
```

**동작 과정:**

1. **uniform 변수 위치 찾기**
   ```cpp
   glGetUniformLocation(ID, "finalBonesMatrices[0]")
   // → 셰이더에서 "finalBonesMatrices[0]" uniform 변수의 위치(인덱스) 반환
   // 예: 위치 = 5
   ```

2. **행렬 데이터 전달**
   ```cpp
   glUniformMatrix4fv(위치, 1, GL_FALSE, &mat[0][0])
   // → GPU의 uniform 변수에 4x4 행렬 데이터 전달
   // mat[0][0]은 행렬의 첫 번째 요소의 주소
   ```

**실제 예시:**

```cpp
// 뼈대 0번 (UpperArm)의 변환 행렬
glm::mat4 upperArmMatrix = transforms[0];
// 예: 30도 회전 행렬

shader.setMat4("finalBonesMatrices[0]", upperArmMatrix);
//    ↓
// glUniformMatrix4fv(위치, 1, GL_FALSE, &upperArmMatrix[0][0])
//    ↓
// GPU의 finalBonesMatrices[0] uniform 변수에 행렬 데이터 저장
```

### 📌 4단계: 셰이더에서 사용

**Vertex Shader 코드:**

```glsl
// animated_model.vs
uniform mat4 finalBonesMatrices[100];  // ← CPU에서 전달받은 뼈대 행렬 배열

layout (location = 5) in ivec4 aBoneIDs;    // 정점의 뼈대 ID
layout (location = 6) in vec4 aWeights;      // 정점의 뼈대 가중치

mat4 getBoneTransform()
{
    // 정점이 영향을 받는 뼈대들의 변환 행렬을 가중치로 합산
    mat4 boneTransform = mat4(0.0);
    boneTransform += finalBonesMatrices[aBoneIDs[0]] * aWeights[0];
    boneTransform += finalBonesMatrices[aBoneIDs[1]] * aWeights[1];
    boneTransform += finalBonesMatrices[aBoneIDs[2]] * aWeights[2];
    boneTransform += finalBonesMatrices[aBoneIDs[3]] * aWeights[3];
    return boneTransform;
}

void main()
{
    // 1. 뼈대 변환 행렬 계산
    mat4 boneTransform = getBoneTransform();
    //    예: finalBonesMatrices[5] * 0.6 + finalBonesMatrices[6] * 0.4
    
    // 2. 정점 위치 변환
    vec4 localPos = boneTransform * vec4(aPos, 1.0);
    //    원래 위치 → 뼈대 변환 적용
    
    // 3. 최종 화면 좌표 계산
    gl_Position = projection * view * model * localPos;
}
```

## 🔄 전체 데이터 흐름

```
[CPU 측]
    │
    ├─ Update() 호출
    │   └─ Animator::UpdateAnimation()
    │       └─ CalculateBoneTransform()
    │           └─ m_FinalBoneMatrices[100] 계산 완료
    │               ├─ [0] = UpperArm 변환 행렬
    │               ├─ [1] = LowerArm 변환 행렬
    │               └─ ...
    │
    └─ Render() 호출
        └─ CharacterBase::Render()
            ├─ transforms = animator_->GetFinalBoneMatrices()
            │   └─ m_FinalBoneMatrices 배열 반환
            │
            └─ for (i = 0; i < 100; i++)
                └─ shader.setMat4("finalBonesMatrices[" + i + "]", transforms[i])
                    └─ glUniformMatrix4fv()
                        └─ GPU의 uniform 변수에 행렬 전달
                            │
                            ▼
[GPU 측]
    └─ Vertex Shader 실행
        ├─ finalBonesMatrices[100] 배열 사용 가능
        │
        └─ 각 정점마다:
            ├─ aBoneIDs와 aWeights 읽기
            ├─ getBoneTransform() 호출
            │   └─ finalBonesMatrices[aBoneIDs[0]] * aWeights[0] + ...
            └─ 정점 위치 변환
                └─ 화면에 그려짐!
```

## 💡 실제 예시: 팔꿈치 정점 렌더링

### 시나리오: 팔꿈치 정점이 렌더링될 때

```
1. CPU에서 뼈대 행렬 전달
   └─ shader.setMat4("finalBonesMatrices[5]", upperArmMatrix)  // UpperArm
   └─ shader.setMat4("finalBonesMatrices[6]", lowerArmMatrix)  // LowerArm
   └─ ... (나머지 98개도 전달)

2. GPU에서 정점 처리
   └─ 정점 데이터 읽기:
       aBoneIDs = [5, 6, -1, -1]  // UpperArm=5, LowerArm=6
       aWeights = [0.6, 0.4, 0.0, 0.0]
   
   └─ getBoneTransform() 호출:
       boneTransform = finalBonesMatrices[5] * 0.6 + 
                       finalBonesMatrices[6] * 0.4
       // UpperArm 변환 60% + LowerArm 변환 40%
   
   └─ 정점 변환:
       localPos = boneTransform * 원래위치
       // 팔이 올라갔다면 정점도 위로 올라감
   
   └─ 최종 좌표:
       gl_Position = projection * view * model * localPos
       // 화면에 그려질 위치 계산 완료
```

## 🎯 핵심 포인트

### 1. Uniform 변수란?

**Uniform**: CPU에서 GPU로 데이터를 전달하는 방법
- 셰이더 프로그램 전체에서 공유되는 변수
- 한 번 설정하면 모든 정점에서 사용 가능
- 예: `finalBonesMatrices[100]` 배열

### 2. 전달 과정

```
CPU 메모리 (m_FinalBoneMatrices 배열)
    ↓
glUniformMatrix4fv() 호출
    ↓
GPU 메모리 (uniform 변수)
    ↓
Vertex Shader에서 사용
```

### 3. 배열 인덱싱

```cpp
// CPU에서
shader.setMat4("finalBonesMatrices[0]", transforms[0]);
shader.setMat4("finalBonesMatrices[1]", transforms[1]);
// ...

// GPU (셰이더)에서
mat4 transform0 = finalBonesMatrices[0];  // 같은 데이터!
mat4 transform1 = finalBonesMatrices[1];
```

```cpp
// 1. Update()에서 계산
Animator::UpdateAnimation(dt)
  └─ m_FinalBoneMatrices[100] 계산 완료

// 2. Render()에서 전달
CharacterBase::Render()
  ├─ transforms = animator_->GetFinalBoneMatrices()
  └─ for (i = 0; i < 100; i++)
      └─ shader.setMat4("finalBonesMatrices[" + i + "]", transforms[i])
          └─ glUniformMatrix4fv()  // GPU에 전달

// 3. GPU에서 사용
Vertex Shader
  └─ finalBonesMatrices[aBoneIDs[0]] * aWeights[0] + ...
      └─ 정점 변환
```
